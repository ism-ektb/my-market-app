# Приложение "Витрина магазина"

Для сборки проекта требуется среда разработки и docker так как в тестах используется Testcontainers.
Команды сборки стандартные gradle clean bootJar.

Для запуска проекта в докере запустить docker-compose.yml из корневой директории.

При запуске программы в среде разработки необходимо предварительно запустить в докере контейнер с базой данных и базой Redis. docker-compose.yml для запуска только базы данных находится в папке /infra.

## Приложение будет доступно по порту 8080.

Сервер платежей доступен по порту 8081.
Для упрощения сервис магазина и сервис платежей хранит данные в одной базе данных, но разных схемах.
При первом запуске сервиса платежей в нем устанавливается баланс 10000.

Данные о товарах размещенных в магазине необходимо ввести "в ручную".
Форма для ввода доступна по адресу localhost:8080/form. В случае удачного/неудачного ввода появится сообщение о статусе ввода и форма для ввода следующей позиции.
### При попытке запуска приложения с пустой базой данных появится ошибка.
Остальные пункты сделаны согласно заданию.
Поиск осуществляется по первым буквам названия товара независимо от регистра.

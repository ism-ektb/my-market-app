# Приложение c веб-интерфейсом "Витрина магазина" основанное на реактивном стеке.

Приложение представляет собой интернет-магазин, состоящий из нескольких сервисов:

- Сервис магазина: Основной сервис магазина (витрина, корзина, заказы).
- Модуль авторизации пользователей: Spring Security c авторизацией по логину и паролю.
- Платежный сервис: RESTful-сервис денежных переводов и управления балансом.
- Сервис авторизации микросервисов: авторизация осуществляется по Client Credentials Flow.

Функционал:

- Просмотр товаров с пагинацией и поиском. Данные о товарах кэшируются в Redis.
- Сортировка товаров по алфавиту и цене.
- Добавление товаров в корзину 
- Регистрация и login пользователя с сохранением истории поиска и содержимого корзины.
- Оформление заказов с проверкой баланса и оплатой через Платёжный сервис.
- Просмотр истории заказов.
- Интеграция между сервисами реализована на основе спецификаций OpenAPI с генерацией реактивного клиентского и серверного кода.



Для запуска проекта в докере запустить docker-compose.yml из корневой директории.
Запуск занимает продолжительное время. У меня на компьютере оно занимает несколько минут. 
Контейнер с основным приложением запускается только после полной загрузки сервера авторизации keycloak.

## Приложение будет доступно по порту 8085.

Предварительно требуется "пополнить" витрину магазина товарами. 
Для этого надо перейти по адресу http://localhost:8085/form (страница доступна только администратору)
Приложение предложит авторизоваться. Необходимо ввести логин "admin" и пароль "admin"
Далее можно будет добавить товары.

После добавления товаров можно перейти на саму витрину. http://localhost:8085 (без товаров будет ошибка)
Администратор не может совершать покупки, ему, как и анонимному пользователю, доступна только витрина
В правом верхнем углу доступна ссылка для выхода из аккаунта. (http://localhost:8085/logout)
После выхода из аккаунта можно зарегистрировать нового пользователя по ссылке в правом верхнем углу. (http://localhost:8085/registration)
Необходимо ввести НОВЫЙ логин и пароль. Например, логин "user" пароль "user".
Одновременно с регистрацией происходит и аутентификация пользователя.
Далее можно совершать покупки. Покупки совершаются с ОБЩЕГО счета.  
При первом запуске сервиса платежей в нем устанавливается баланс 10000.

## Запуск из среды разработки.

Необходимо воспользоваться контейнерами Баз дынных и сервиса авторизации из предыдущего пункта.
Сервер платежей доступен по порту 8081.
Основной сервис по порту 8085.
Сервис авторизации доступен по порту 8080. (логин "admin" пароль "admin")

Для запуска тестов необходим докер.
